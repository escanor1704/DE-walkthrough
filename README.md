# SQL Practice Projects

This repo is where I keep my SQL work as I learn. It started with basic commands and grew into two small projects: building a data warehouse and then exploring the data inside it.

## What's in here

**DW_Build**
This is where I built a data warehouse from scratch. I created the database and tables, loaded the raw data, cleaned it up, and organized it into tables that are easier to report on. Most of the work here was about getting messy data into a clean, usable shape.

**EDA**
Once the warehouse was ready, I used this folder to explore the data. These queries look at things like date ranges, totals, top and bottom performers, and how different categories compare. Basically, this is me asking questions and seeing what the data says.

**into.sql**
My starting point. It has the basic SQL commands I practiced first: SELECT, WHERE, ORDER BY, GROUP BY, joins, and inserting, updating and deleting rows.

## How to run it

1. Run the scripts in DW_Build first to set up the warehouse.
2. Then run the queries in EDA to explore the data.

I used SQL Server, but most of the queries should work in other databases with small changes.
